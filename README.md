# Mis Finanzas

App de finanzas personales: gastos e ingresos del mes, presupuesto, fondos compartidos, tarjeta y meta de ahorro.
Funciona sin conexión (agrégala a la pantalla de inicio desde Safari).

Este repositorio no contiene datos personales: lo que registras se guarda solo en tu teléfono.
Usa el botón 💾 de la app para guardar o cargar un respaldo.
